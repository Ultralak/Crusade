# Crusade
Crusade is a bullet hell like game made and created in Godot

The game features 14 weapons, 4 different enemies and 2 levels

The games use procedural generation similar to that of the Binding of isaac in that there are no hallways between different rooms. This was primarily done to speed up development

Controls : 
WASD - move up, left, down, right
shift - dash
left-mouse : slot 1 weapon
right-mouse : slot 2 weapon

Picking up weapons works by equipping the weapon to either the active ( showing weapon ) if your inventory is full 
if any slot is empty the weapon is equipped there

Currency is energy/coins which you use to buy weapons and shoot weapons and which you gain from killing enemies (Spend wisely)

Roguelike elements such as permadeath and no health pickups except on new levels

Enemy types : 

Sniper : 
Keeps his distance and fires very fast projectiles

Shotgun:
Up close and personal lad who will stop at nothing to blow up your face

Assault:
Typical soldier marching towards your demise

Fly:
Watch out for the attack


Weapons include shotgun, grenade launcher (basically ;) assault rifle, burst rifle, automatic shotgun and Smg with some very basic and very advanced machinery per level
The better the weapon the higher the cost 

To run to game please download from the following demo link : https://ultrala.itch.io/crusade
